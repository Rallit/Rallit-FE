## 서비스 소개

Rallit은 내 조건에 맞는 테니스 매치를 찾고, 코트를 확보한 사용자와 함께 경기할 참가자를 연결하는 모바일 웹 서비스입니다.

실력과 희망 일정에 맞는 매치를 추천받아 참가하거나, 확보한 코트를 등록해 직접 참여할 매치를 개설할 수 있습니다.

<br />

## 주요 기능

현재 초기 개발 단계이며, 아래는 **MVP 기준 구현 예정 기능**입니다.

| 기능                  | 설명                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------- |
| 회원가입 · 프로필     | 회원가입, 기본 프로필과 테니스 실력 및 경기 조건 설정·수정                                         |
| 매치 추천 · 탐색      | 실력, 지역, 희망 일정, 경기 유형에 맞는 매치 추천 및 탐색. 일치하는 매치가 없으면 유사한 매치 제안 |
| 매치 상세 · 참가      | 경기 정보와 취소 정책 확인, 참가 신청 및 취소, 신청 상태 조회                                      |
| 코트 인증 · 매치 개설 | 코트 예약 증빙 제출과 매치 개설 신청. 코트 인증과 필수 정보 확인 후 공개 모집                      |
| 개설한 매치 관리      | 호스트의 참가 신청 수락·거절, 모집 현황 확인, 인원 미달이나 취소 발생 시 후속 처리                 |
| 입금 안내 · 참가 확정 | 참가비, 입금 계좌 및 기한 안내, 운영자의 수동 입금 확인, 참가 및 매치 확정 상태 조회               |
| 내 매치 · 경기 안내   | 신청한 매치 조회, 확정된 경기 일정과 코트 이용 정보 확인, 경기 당일 긴급 문의                      |
| 경기 완료 · 참여 이력 | 경기 참여 완료 처리, 참여 이력 저장 및 조회                                                        |
| 알림                  | 참가 신청 상태와 매치 확정·취소·변경 안내, 경기 전 리마인드, 코트 인증 승인·반려 안내              |
| 운영자 관리           | 코트 증빙 검수, 매치와 참가자 관리, 수동 입금 확인, 환불·정산 및 예외 상황 처리                    |

> 랭킹, 경기 결과 상호 인증, 후기와 매너 평가, 클럽, 입금 기한 알림은 핵심 기능 구현 후 검토합니다. 승급전 진행은 데모데이 이후 개발 범위입니다.
